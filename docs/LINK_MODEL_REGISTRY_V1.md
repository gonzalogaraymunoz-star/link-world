# LINK WORLD · Registro de Modelos v1

El Registro de Modelos es la capa que convierte aprendizaje disperso en una cartera económica jugable.

## Flujo

DOLOR → HOBBY → MODELO CANDIDATO → EVIDENCIA → REPETIBLE → PRODUCTIZABLE → CANDIDATO A NEGOCIO → NEGOCIO → REPLICABLE.

Un modelo no se promueve por intuición. Se mueve cuando existe evidencia suficiente para cruzar el siguiente gate.

## Objetos persistentes

- `link_world_models`: definición, dolor, solución, madurez, rol económico y gate.
- `link_world_model_evidence`: evidencia positiva o negativa, siempre con fuente y estado de verificación.
- `link_world_model_business_links`: dónde nació, dónde fue validado o instalado.
- `link_world_model_portfolio_v`: proyección jugable con readiness heurístico.

El readiness es una heurística de navegación, no una predicción financiera.

## Primera cartera

La instalación inicial reconoce modelos provenientes de evidencia ya existente: Operational House, Contenido/RRSS Caracol, Karaoke recurrente, intermediación turística, venta consultiva conversacional, LINK Digital, Flash Botox y productos comerciales en exploración.

## Regla económica

Producto y negocio no son sinónimos.

- Modelo: cómo resolver.
- Producto: cómo empaquetar y vender.
- Negocio: mercado + economía + responsabilidad + operación + continuidad.

LINK Director decide cuándo un candidato cruza el umbral a negocio. La interfaz no crea negocios automáticamente.
