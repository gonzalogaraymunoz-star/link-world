# LINK FRONT PRESENCE PROTOCOL · v1

Este protocolo es obligatorio para cualquier front, micrositio, dashboard o experiencia pública donde aparezca la marca LINK.

## Objetivo
Que LINK nunca aparezca como una marca aislada o ambigua. Cada aparición debe permitir:
1. entender qué es LINK;
2. comprender cómo un negocio puede transformarse dentro de la red;
3. descubrir cómo asociarse;
4. iniciar un precontacto verificable;
5. llegar a WhatsApp con contexto suficiente para una reunión.

## Flujo canónico

### 1. Botón «¿Qué es LINK?»
Cada front donde aparezca LINK debe ofrecer un acceso visible pero sobrio a:

`/que-es-link/`

El botón no debe competir con la acción principal del negocio, pero siempre debe estar disponible.

### 2. Landing «¿Qué es LINK?»
La landing explica LINK desde el punto de vista del negocio:
- qué cambia cuando un negocio entra a LINK;
- cómo LINK entiende, conecta, activa, comprueba, aprende y amplía posibilidades;
- modelos asociativos;
- LINK Cupones y su lógica económica;
- ejemplos concretos de negocios y capacidades del ecosistema;
- acceso a «Ser parte de LINK World».

Debe mantener el criterio:
**resumen visible + detalle al clic**.

### 3. CTA «Ser parte de LINK World»
Toda llamada pública a entrar a LINK World debe pasar primero por:

`/ser-parte/`

No se envía tráfico público directamente al panel privado.

### 4. Landing receptiva «Ser parte»
Debe comunicar que LINK World es una central de control y una red privada de conexiones.

Mensaje base:
**LINK World es una central de control. Para acceder y ser parte del mundo de conexiones, contáctanos.**

La narrativa debe mostrar transformación:
- entendemos el negocio;
- detectamos oportunidades;
- conectamos capacidades;
- activamos operaciones;
- medimos, aprendemos y escalamos.

### 5. Formulario de precontacto
Antes de abrir WhatsApp, pedir datos duros:
- nombre;
- negocio;
- Instagram;
- correo;
- por qué le interesa LINK.

El formulario debe:
- validar los campos;
- registrar el lead;
- crear una solicitud de LINK World;
- dejar el estado como pendiente de verificación;
- no crear automáticamente un nodo real en Micelio.

### 6. WhatsApp preparado
Al completar el formulario, abrir WhatsApp con un mensaje prearmado que incluya:

- nombre;
- negocio;
- Instagram;
- correo;
- motivo de interés;
- referencia interna del lead cuando exista.

Objetivo: que el primer mensaje recibido ya permita preparar la reunión.

### 7. Verificación antes de Micelio
Regla:
**Formulario enviado ≠ conexión real.**

Sólo después de verificar el contacto puede considerarse su incorporación al Micelio o a una relación real dentro de LINK World.

## Jerarquía de rutas
`Front del negocio → ¿Qué es LINK? → Ser parte de LINK World → Precontacto → WhatsApp → Reunión → Verificación → Micelio`

## Criterio visual
- minimalista;
- sobrio;
- provocador sin ser críptico;
- acento ácido LINK;
- sin saturación;
- una idea principal por tarjeta;
- detalles mediante popovers/modal suave;
- ningún texto o icono debe solaparse;
- responsive obligatorio;
- priorizar comprensión antes que efecto visual.

## Regla de producto
Cada nuevo front creado dentro del ecosistema LINK debe comprobar este protocolo antes de considerarse completo.
